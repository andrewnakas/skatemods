## Skater XL

Skater XL supports maps out of the box. Script mods need a loader.

1. **Maps:** subscribe on [mod.io](https://mod.io/g/skaterxl) or use the in-game Mod Browser (this works on console too).
2. **Script mods:** install **[Unity Mod Manager](https://www.nexusmods.com/site/mods/21)**, always the latest version, and point it at your Skater XL folder. Then add mods such as:
   - **[XLGearModifier (XLGM2)](https://mod.io/g/skaterxl/m/xlgearmodifier):** dynamic clothing, custom character models, unlimited gear customization
   - **[XXLMod](https://github.com/DawgVinciSXL/XXLMod):** stats and movement tuning. Install the version that matches your game, or the camera breaks
   - **XL Menu Mod / Map Patch:** needed for maps that use custom scripts
3. **Making maps:** start with the [Skater XL mapping wiki](https://github.com/SkaterXLModding/skater-xl-mapping-wiki/wiki/Map-Scripting).

Game updates sometimes break map lighting. If a map looks wrong after a patch, check for a re-release.

## Session: Skate Sim

Session doesn't officially support mods, so patches can break them at any time.

1. Install [Session Mod Manager](https://rodriada000.github.io/SessionMapSwitcher/).
2. Click **Patch With [Illusory](https://illusory.dev/) Mod Unlocker**. Without it, custom maps and textures don't load.
3. Download maps, decks, wheels and shirts from the Mod Manager's **Asset Store**, or from the [Illusory Discord](https://discord.gg/Mt3qzgN).
4. Switch maps from the Mod Manager while the game runs.

On Steam Deck, follow the [Proton modding guide](https://hackmd.io/@agentender/H102AjAro).
