question: reTHAWed or THUG Pro, which is better?
answer: Both put levels from the whole Neversoft series into one PC game. THUG Pro runs on THUG2 and is built around online sessions and custom levels. reTHAWed runs on American Wasteland, keeps THAW's story mode, and since 5.0 adds THUG2's story and classic tours. Many players install both.

## Side by side

| | THUG Pro | reTHAWed |
|---|---|---|
| Base game | Tony Hawk's Underground 2 (PC) | Tony Hawk's American Wasteland (PC) |
| Made by | the THUG Pro team, hosted by THPSX | 10K Rising (lead developer Zedek) |
| Since | 2013 | first beta in 2017 |
| Current version | 0.7, from October 2023 ([changelog](https://thugpro.com/post/thugpro-v0-7-0-0-changelog/)) | 5.0, from October 4, 2026 ([release](https://gitgud.io/10k-rising/rethawed-release-repository/-/commit/77a4c25929f958c9bfec0f413a2f00ada6877333)) |
| Moveset | THUG2 | THAW, including walking and the bike |
| Story modes | none | THAW's and, since 5.0, THUG2's |
| Classic mode | no | THPS2, THPS3, THUG2 and Project 8 classic tours |
| Custom content | custom levels, soundtracks, Create-A-Theme | custom skaters, decks, items and levels as mods |
| Online | [OpenSpy](https://openspy.net/) | OpenSpy |
| Install | [thugpro.com](https://thugpro.com/) | the reTHAWed Updater from [rethawed.com](https://www.rethawed.com/), Windows or Linux |

Both need your own PC copy of the base game.

## Pick THUG Pro if

- You want **online sessions**. THUG Pro was built to [unify the online community](https://thpsx.com/thugpro-info/) after the official servers closed, and it's where custom level makers have published for years ([history](/history/thug-pro/)).
- You prefer THUG2's moves and speed.

## Pick reTHAWed if

- You want **single-player content**. reTHAWed has two full story modes and classic tours, with a Hardcore difficulty for the THAW tour ([history](/history/rethawed/)).
- You want walking, the bike and THAW's movement in every level.
- You want a mod that's updated often. reTHAWed shipped 4.1 through 5.0 between June 2024 and October 2026, while THUG Pro's last release was 0.7 in 2023.

## Or both

They install side by side, since each needs its own base game. Add [PARTYMOD](/history/partymod/) if you also want the original games patched for modern PCs. Setup: [Get started with THUG Pro, reTHAWed and PARTYMOD](/guides/thug-pro-and-partymod/). What 5.0 added: [reTHAWed 5.0](/blog/rethawed-5/).
