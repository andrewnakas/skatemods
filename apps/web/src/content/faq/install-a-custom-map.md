## Pick your platform

| You play on | Download | Guide |
|---|---|---|
| skate3recomp (PC, Mac, Linux) | the **recomp `.big`** | [Install community maps with the Level Loader](/guides/install-community-maps/) |
| RPCS3 | the **PS3** original | [Mod Skate 3 on RPCS3](/guides/skate-3-on-rpcs3/) |
| Skate 3 Rust engine | the **`.skate`** file | [.skate maps in the Rust engine](/guides/skate-maps-rust-engine/) |
| Modded PS3 | the **PS3** original | copy it over the game files, the same way as on RPCS3 |

Every map page on [skatemods](/maps/) lists the formats available for that map.

## Before you start

- **Back up** any game files you replace. On PS3 and RPCS3 a map usually overwrites an existing district or DLC slot.
- **Credit the author.** If you share a video, link the map page.
- If a map crashes on one platform but not another, [report it](/policy/#takedowns) from its map page so the conversion can be checked.
