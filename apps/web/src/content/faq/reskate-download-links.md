## Direct downloads

These links always point at the newest release:

- [ReSkateLauncher.exe](https://github.com/Dingo-Shenanigans/ReSkate/releases/latest/download/ReSkateLauncher.exe) and [ReSkate.dll](https://github.com/Dingo-Shenanigans/ReSkate/releases/latest/download/ReSkate.dll), the two files you put beside `Skate.exe`.
- The full zip is named after its version (`ReSkate-2.0.2.zip`), so get it from the [releases page](https://github.com/Dingo-Shenanigans/ReSkate/releases/latest). It holds the same two files plus licenses.
- The dedicated server, `ReSkateServer-<version>.zip` for Windows and `ReSkateServer-Linux-<version>.tar.gz` for Linux, is on the same page. See [Host a ReSkate server](/guides/host-a-reskate-server/).

Once installed, the launcher updates itself, so you only download it once.

## Avoid mirrors

ReSkate isn't on Nexus Mods, Mediafire or any other host, and the team doesn't send it in DMs. Windows Defender flags the official download too (a machine-learning guess, explained in [Is ReSkate safe?](/faq/is-reskate-safe/)), so a warning doesn't tell you which copy is real. Where you got it does. Setup is in [download, install and play](/guides/play-skate-with-reskate/).
