## Skater XL: official and cross-platform

Easy Day Studios added an in-game **Mod Browser** in [update 1.1](https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/3917534300074086855), "allowing access to browse, download, and install mods without ever leaving the game", on PC, PlayStation and Xbox. It runs on [mod.io](https://mod.io/g/skaterxl). Script mods that change gameplay are still PC-only and installed by hand. The studio also hired modders and shipped community maps in 1.0 ([history](/history/skater-xl/)).

## Session: community-run

Session is an Unreal Engine 4 game. crea-ture said official mod tools would come "eventually" ([Steam](https://steamcommunity.com/app/861650/discussions/0/2763442118821365907/)), and so far players rely on community tools. [Session Mod Manager](https://github.com/rodriada000/SessionMapSwitcher) by rodriada000 patches the game with the Illusory Mod Unlocker and installs maps and gear. Its Asset Store and its Linux support are both community work. Maps are built in the regular UE4 editor ([history](/history/session/)).

## In practice

| | Skater XL | Session |
|---|---|---|
| Official mod support | yes, mod.io | no |
| Consoles | maps and gear | no |
| Install | in-game browser, or Unity Mod Manager for scripts | Session Mod Manager |
| Map tools | Unity, plus the [mapping wiki](https://github.com/SkaterXLModding/skater-xl-mapping-wiki) | UE4 editor |
