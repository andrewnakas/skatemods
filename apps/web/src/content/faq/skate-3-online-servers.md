## Skate 3 Blaze Server (active)

[skate6743/Skate3BlazeServer](https://github.com/skate6743/Skate3BlazeServer) is a "Skate 3 Custom Blaze server for RPCS3/PS3 with working matchmaking and content server features":

- matchmaking and invites from your in-game friends list,
- relay servers for each lobby, so players don't connect peer-to-peer,
- Skate.Park uploads and downloads.

There's a public server you can join, and the README explains how to host your own, publicly or over a VPN with friends. Connecting takes a few RPCS3 settings; [Can I still play Skate 3 online?](/faq/skate-3-online/) walks through it. It doesn't support Xenia or the PC recomp.

## Skateboard3Server (archived)

[hallofmeat/Skateboard3Server](https://github.com/hallofmeat/Skateboard3Server) was a "Custom Server compatible with Skate 3" (MIT). Its README lists authentication as done and invites, matchmaking and web features as in progress. The repository was archived in January 2025, so it isn't being developed.

## EA's servers

EA's own servers went down around 2016 and [came back in 2018](https://www.kitguru.net/gaming/ryan-burgess/skate-3-servers-are-back-up-years-after-they-unofficially-shut-down/) without an announcement. Don't count on them.

## Without the original game

[Clean Room Skate Online](/skate-3-online/) is a fan-made rewrite in your browser. Its multiplayer menu opens a private room with an invite link, or a public room, for up to 10 skaters. The Skate 3 Recomp has no online mode yet ([details](/guides/skate-3-recomp/#online-play)).
