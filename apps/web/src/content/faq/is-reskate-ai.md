## ReSkate itself

ReSkate is open source under the GPL-3.0, and its README ends with an AI disclosure. It says parts of the project, "including code, reverse-engineering notes and documentation", were written with the help of AI coding assistants. The maintainers direct and test that work, and the README asks people to open an issue if something looks wrong ([README](https://github.com/Dingo-Shenanigans/ReSkate#ai-disclosure)). Some commits also carry a co-author line naming an AI assistant ([example](https://github.com/Dingo-Shenanigans/ReSkate/commit/e3ec512878)).

ReSkate has 23 contributors on GitHub, and each change goes in as a reviewed commit or pull request. Because the code is public, anyone can read what the launcher and runtime do, whoever or whatever typed it.

## The "AI Generated" tag on Thunderstore

Thunderstore lets authors tag their packages. On October 10, 84 current ReSkate packages carried **AI Generated** ([the tag on Thunderstore](https://thunderstore.io/c/reskate/?included_categories=2761)), about half of them cosmetics and board graphics. The tag is the author's own label. Thunderstore doesn't check it, so an untagged mod isn't proof that no AI was involved.

skatemods lists every current mod, tagged or not, with its tags on the [mod's page](/reskate/).
