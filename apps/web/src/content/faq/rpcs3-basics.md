## Compatibility

RPCS3's [compatibility list](https://rpcs3.net/compatibility?g=BLUS30464) rates Skate 3 **Playable** for BLUS30464 (US), BLES00760 (EU) and BLJM60296 (Japan).

## Setup in three steps

1. **Install RPCS3**, then the PS3 system software. The [quickstart](https://rpcs3.net/quickstart) explains that RPCS3 "requires the PlayStation 3 system software, contained in PS3UPDAT.PUP". Install it from **File > Install Firmware**.
2. **Dump your own disc** with a PS3 running custom or hybrid firmware, or with a compatible PC Blu-ray drive ([how](/faq/dumping-your-own-games/)).
3. **Add the game** to RPCS3 and install the latest game update.

## Modding on RPCS3

The emulator era produced most of the classic Skate 3 tools: texture tools, a park swapper, the CH3AT trainer, S3GE board graphics, and QTS3native for menus. The [Skate 3 history](/history/skate-3/) lists them with links. Custom maps replace files in the game folder. See [Mod Skate 3 on RPCS3](/guides/skate-3-on-rpcs3/).

## Online

Players on RPCS3 can go online again through [skate6743's Blaze server](https://github.com/skate6743/Skate3BlazeServer). Some emulator settings have to match everyone else's. See [Can I still play Skate 3 online?](/faq/skate-3-online/)
